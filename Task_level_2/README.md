# Tasks Implemented

## 1. Web Scraper (`Web_Scraper.py`)

This project demonstrates web scraping using the **Scrapy Framework** in Python.

The scraper connects to the official ShadowFox website:

https://www.shadowfox.org.in/

and extracts useful information such as:
- Website Title
- Headings (`h1`, `h2`, `h3`)

The extracted data is:
- displayed in the terminal
- stored inside a CSV file (`scraped_data.csv`)

### Concepts Used
- Scrapy Framework
- CSS Selectors
- Data Extraction
- CSV File Handling
- Error Handling
- Web Crawling

---

## 2. Hangman Game (`Hangman.py`)

This project is a simple text-based implementation of the classic **Hangman Game** using Python.

The game:
- randomly selects a word
- asks the user to guess letters
- tracks correct and incorrect guesses
- displays hidden word progress
- ends with either a win or loss condition

The project demonstrates how loops, conditions, lists, strings, and user input can be combined to build an interactive console game.

### Concepts Used
- Random Module
- Loops
- Conditional Statements
- Lists and Strings
- User Input Handling
- Game Logic
- Win/Loss Conditions
