# ShadowFox Python Internship - Beginner Task

This repository contains my submission for the **Beginner Level Task** of the **ShadowFox Internship**.

Although the task mentioned implementing **any 5 out of 9 programs**, I decided to complete **all 9 tasks** to improve my understanding of Python fundamentals and gain more hands-on practice.

---

# Tasks Implemented

## 1. Variables (`Variables.py`)
This program demonstrates the use of variables, data types, and arithmetic operations in Python.  
It includes checking variable types, understanding reserved keywords, and calculating Simple Interest using mathematical formulas.

---

## 2. Numbers (`Numbers.py`)
This program focuses on numerical operations and string formatting.  
It includes formatted string representation, area calculation of a circular pond, water quantity calculation, and speed calculation using formulas.

---

## 3. List (`List.py`)
This program demonstrates various list operations in Python using a Justice League superhero dataset.  
It includes adding elements, removing elements, sorting lists, inserting values at specific positions, and updating complete lists.

---

## 4. If Condition (`Condition.py`)
This program demonstrates decision-making using conditional statements (`if`, `elif`, `else`).  
It includes BMI category prediction, country identification based on city names, and checking whether two cities belong to the same country.

---

## 5. For Loop (`Loop.py`)
This program demonstrates looping concepts using Python `for` loops.  
It includes simulating dice rolls with statistics tracking and a jumping jacks workout program with user interaction and break conditions.

---

## 6. Dictionary (`Dictionary.py`)
This program demonstrates the use of dictionaries and tuples in Python.  
It includes storing trip expenses, calculating total expenses, comparing spending patterns, and identifying the category with maximum expense difference.

---

## 7. File Handling (`File_Handle.py`)
This program demonstrates CSV file handling in Python.  
It reads student data from a CSV file, calculates total and average marks for each student, and writes the updated data into a new CSV file.

---

## 8. Classes and Objects (`Class_Obj.py`)
This program demonstrates Object-Oriented Programming concepts using classes and objects.  
It creates an `Avenger` class with superhero properties, methods for displaying information, and leader identification functionality.

---

## 9. Inheritance (`Inheritance.py`)
This program demonstrates inheritance in Python using a `MobilePhone` base class and `Apple` and `Samsung` child classes.  
It includes constructors, method inheritance, unique brand-specific features like iOS and Android versions, and object creation with different properties.
